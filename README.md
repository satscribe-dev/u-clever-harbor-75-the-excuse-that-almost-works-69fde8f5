A program that writes the one line a gamer texts the boss to skip work on
GTA 6 launch week: HR moved the annual leave by mistake and payroll already
locked it, so the day off is the system's own doing.

Run `node main.ts`; it writes the entry to `/output/entry.txt`
(96 characters, 18 words, one line — inside the gate of 1–140 characters
and at most 20 words).

Entry for the [make.fun bounty](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5).
